# Exceptions, special treatment, and limits

An **exception** is an error or an alternative outcome. An **exemption** is a deliberate rule that skips or treats something differently. An **analysis limitation** means the available evidence cannot establish the answer. They are kept separate below. Recommendations are in [findings](key_findings.md), not presented here as current behavior.

## Analysis limitations

Only the checkout's `learner_day5` application and its present docs/tests/data were available. All source bodies were inspected, but no live SDK, web host, authenticated session, database, deployment, or realistic concurrent workload was supplied. No dependency was installed, no network service called, and no source fixture modified. Test coverage is selective: 12 tests pass, but do not exercise every edge in these tables. See [verification limits and open questions](verification_and_open_questions.md#verification-limits) for the exact exclusions and evidence needed to resolve them.
