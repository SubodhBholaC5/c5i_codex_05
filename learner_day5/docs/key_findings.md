# Findings and suggested next steps

The table separates observed behavior from recommended changes. No application fixes were made. Priority reflects potential consequence and evidence strength in this lab, not a claim that a production deployment exists. **Confirmed** means the code demonstrates the behavior; executed probes and tests are recorded separately in [verification](verification_and_open_questions.md).

## Hypotheses and unresolved risks

| ID | Finding | Category | Impact | Evidence | Confidence | Suggested next step |
|---|---|---|---|---|---|---|
| H01 | Identity is caller supplied; no authentication in this adapter | Integration requirement | If exposed directly without a trusted wrapper, user isolation cannot establish authorization | [adapter:7–14](../src/api.py#L7-L14), [authenticated intent:4,31](feature_contract.md#L31-L31) | Absence in adapter confirmed; deployment exposure unresolved | Inspect intended host and identity middleware before exposure |
| H02 | Model configuration changes may reuse old results | Cache identity | Changing `status`/`wrong_claim` on the same class and same service can leave class-name key unchanged | [model settings:14–15](../src/model.py#L14-L15), [key wiring:12](../src/service.py#L12-L12), [key:7](../src/cache.py#L7-L7) | Mechanism confirmed; real operating scenario inferred and untested | Define whether collaborators may change during a service lifetime |
| H03 | Unbounded cache may grow with unique requests | Capacity concern | Long-lived process plus many distinct keys retains results without eviction | [cache:5–12](../src/cache.py#L5-L12) | Mechanism confirmed; workload impact inferred, unprofiled | Measure realistic lifetime and cardinality before selecting limits |
| H04 | Strict equality is weaker than strict evidence typing | Validation edge | Python numeric/boolean equality can accept `0` for false; missing source field can compare equal to submitted `None` | [shape evidence check:25–26](../src/validation.py#L25-L26), [comparison:11–12](../src/semantic_validation.py#L11-L12) | Static inference; not runtime-verified in this analysis | Add representative type/missing-field cases if stricter semantics are required |

No performance bottleneck is established by the small local benchmark. Its observed speedup shows skipped simulator work only; realistic concurrency, cloud latency, and production storage were not measured ([benchmark implementation:9–23](../src/benchmark.py#L9-L23), [verification limitations](verification_and_open_questions.md#verification-limits)).
